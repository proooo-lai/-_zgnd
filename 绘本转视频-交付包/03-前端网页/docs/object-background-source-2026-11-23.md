# 对象背景拒答修复记录

用户确认的问题是：在当前导入成片约 23 秒处点选人物，能识别对象，但自动背景介绍返回证据不足。本次沿用已配置的互动视觉、文本和语音服务，不新增密钥，不补跑尚未完成的整书读图，不生成视频。

## 已复现的原因

原链路优先调用文本模型。模型能够从现有页面描述给出部分相关情节，却因为无法确认角色姓名、动机或身世，将整段标为不确定；校验层因此拒绝整段回答。此类证据性拒答还被存为同一对象的可复用结果，手动再次获取时也可能直接复用旧拒答。冻结目标的描述只作为文本线索，缺少原书插图的对应核对。

## 本次改动

- 自动背景优先使用互动视觉，附上冻结点击原帧、同尺寸点击标记参考以及最多三个候选原书页图。当前原书页优先提供完整上下文。附图逐一声明角色：视频及标记仅用于辨认所选对象，故事事实来自原书，不将点击框套用成原书对象框。
- 只要求介绍当前原书页能确认的情节或作用；有充分证据再补充关系。姓名、动机和身世不是必答项，不因这些未知事项而放弃其他已确认内容，也不凭外观猜姓名。对象本身或情节仍无法确认时继续拒答。
- 独立复核同样核对引用原书图文及对象对应关系。候选和复核都必须使用 `book` 作用域；视频画面不能单独证明原书情节。原书图缺失时不将视频参考提升为故事证据。仅配置文本时仍保留原有文字证据路径。
- 背景版本更新为 `object-background-source-visual-v4`，旧版缓存失效。仅已确认结果可复用；未确认结果不永久缓存，并显示“重新获取背景”。只有用户点击才再次请求，沿用原有取消、权限和会话隔离规则。
- 不改变普通主窗口问答、当前动作与原书背景分别核对的追问流程，以及中文问题中文回答、英文问题英文回答规则。

数据发送范围增加了自动背景的原书页图与冻结对象参考，发送给现有互动视觉服务；语音服务只接收已核对的回答。来源、原始模型响应、配音和截图仍只保存在本机忽略目录，赛事材料及完整问答不进入公开提交。没有写入指定书名、角色事实、对象框或固定答案。

## 实际验证

- 修改前，以同一冻结对象复现文本模型返回 `uncertain=true`，校验返回 `uncertain_or_invalid_references`。复现请求仅保存在隔离数据目录，没有改写用户会话。
- 修改后，同一冻结对象的真实模型调用使用两次视觉请求（生成和独立复核），返回 `supported` 并引用当前原书页，约 12.037 秒；此项关闭 TTS。
- 本机 Chrome 通过实际指针重新点击同一位置，使用真实对象识别、原书背景及 TTS，没有替换服务响应。独立窗口显示背景和原书第 2 页依据，主窗口历史不变，视频保持暂停，提问按钮可用，页面脚本错误为 0。点击至背景完成约 26.252 秒，背景服务端约 14.979 秒；返回单声道 24 kHz WAV，非空且可解析，时长 16.48 秒。未进行声学回环或人工听音验收。
- 新增回归先复现失败，再验证原书视觉路径、当前页优先、视频/原书作用域隔离、复核拒绝与不确定、原书图缺失、拒答后重试，以及对象窗口重试入口。完整自动回归为 432 项通过，6 条既有依赖弃用警告；对象脚本语法、依赖一致性和差异检查通过。

本次只证明这一处真实故障已复现且修复后的小样能得到有据背景，不代表所有对象、跨页身份或其他书目都已验证。生成和复核仍可能共享模型偏差，需指定人员核验事实及儿童内容安全。原书其余 9 页图像理解继续保持未完成，未恢复批量调用；全书泛化、正式评测和最终交互延迟门槛仍待后续验收。
