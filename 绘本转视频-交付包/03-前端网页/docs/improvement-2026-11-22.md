# 全书试跑后的点选与保真改进

本轮依据用户“进行改进”的要求，处理之前已定位的多分镜点选问题，修补文字区域合并，并评估原图细节保护。没有新增生视频提交，没有读取赛事 Query 或隐藏答案，原失败运行及未发布状态没有被改为成功。

## 已进入正常交互的改动

- 点击时发送实际整帧、整帧标记，以及点击附近未标记/标记的放大局部。边缘处移动裁剪窗口，保留真实像素，不补造画面；记录裁剪窗口、原帧尺寸及坐标约定。
- 定位输出必须显式声明 `coordinate_space=crop|full_frame`，代码按像素边界换算为现有整帧归一化 xywh。缺字段、错误单位/类型、越界、低置信度及不含点击点的候选继续拒绝；不将局部框默认当成整帧框。
- 对象名称只要求可见类别/外观，不要求模型猜人物姓名。动作和原书情节分别由实际帧和原书证据支持。
- 动作生成和独立视觉复核共享同一冻结帧及局部放大，避免只修初次识别、追问仍依赖拥挤整帧。对象助手继续使用自己的记录，主聊天不写入这些轮次。
- 文字合并不再因已有 PDF 正文框而整体丢弃视觉正文框。保留 `native_text`、带来源的正文 `words` 和单独 `visual_words`；匹配容忍换行及常见引号样式差异，原文不被规范化覆盖。既有书库未自动改写。

## 实际验证及限制

先在改动前运行新增回归，复现缺少局部图、无法换算、手写区域丢失、缺坐标系被接纳等问题，修补后再运行。最终完整离线测试 **315 passed、0 failed、0 skipped**，6 条既有依赖弃用警告；`pip check`、差异格式检查通过。原创合成视频另使用实际 FFmpeg 编码/解码，核对保护像素、原片指纹/时长和未保护区域仍有运动。独立代码复审指出的坐标默认值、排版匹配及诊断标识符校验写库问题均补回归修复。

真实服务只使用已保存的授权画面。最初只改点选时，原失败多分镜点位、小目标和空白各检查一次，分别正确识别、正确识别、未识别；单次服务端时间为 6.168、4.996、4.764 秒，但随后的动作追问被复核拒绝，没有计作成功。将局部图扩展到追问生成和复核后，新建对象助手再次点选，8.075 秒识别成功；一次自拟动作追问在 27.29 秒内取得当前动作、相关原书背景、对应页面证据及有效回答 WAV。两路事实复核通过，主会话记录仍为空。

这些检查通过隔离 ASGI HTTP 路由及真实配置服务完成，包含服务端处理及回答语音生成；不是实际浏览器、真人麦克风或扬声器听音，不包含点击到听到首音的端到端延迟。不同代码阶段的小样不能合并成准确率统计或官方成绩，也不能代表跨书泛化和长时间稳定性。回答模型及复核模型仍可能存在共同错误。

显式诊断命令另以既有片段运行一次本地处理，源书文件列表、大小和修改时间未变化，没有调用模型。确认空闲后，默认 8765 工作台已重新加载当前代码；首页、状态及 7 个对象助手接口可访问。这不替代实际浏览器交互验收。

## 视频细节保护：试验失败，未启用默认修复

新增 `storybook/fidelity.py` 和显式 `tools/inspect_saved_video_fidelity.py`。试验用原图像素保护正文及高置信度小物件的有限区域，保留原片、处理版本、区域来源、覆盖率、变换假设及文件指纹；覆盖面积过大直接拒绝。这里只假设固定参考构图，不冒称已经测量了物体运动或配准。

5 份既有质量失败片段中，1 份因保护面积超过内部上限未合成；其余 4 份在本机编码后实际抽帧。原文/物件能被贴回，但生成画面已经漂移，出现拼接缝、重影和细节重复。对处理结果的真实三帧复核全部拒绝，没有成功候选。检查增加了严格 `protection_aligned` 字段，缺失、非布尔 true 或无法确认对齐时均拒绝；原片和候选核对记录分开保存。

因此，这条路径**仅保留为显式诊断工具**，不会在正常绘本导入中自动运行。默认生成仍沿用原片质量门槛；新增模拟整条云流程回归确保原片拒绝后不会进入实验合成、编码或发布，也不会再次提交视频。独立诊断输出位于忽略的 `artifacts/`，不修改书库/历史数据库。工具使用说明见主 README。

下一步视频工程应先验证可靠的画面配准/跟踪或其他保真生成控制；只有真实样本证明合成边界和对象持久性可靠后，才考虑接入正常流程。此前失败片段不能靠放宽审核、整页静态替换或重复付费抽样视为解决。
