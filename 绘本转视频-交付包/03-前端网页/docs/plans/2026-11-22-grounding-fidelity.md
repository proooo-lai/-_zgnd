# 点选与生成保真改进实施计划

依据：用户要求改进全书试跑暴露的问题；赛事事实和数据边界沿用根目录 `AGENTS.md`。本文件是工程实施计划，不新增赛事门槛。

## 验收行为

1. 点选同时提供整帧与点击局部放大，明确记录裁剪变换；模型必须声明整帧或局部坐标，代码转换并继续核对点击点、坐标类型及置信度。邻居框和空白不能被放宽接纳。
2. 文字合并保留 PDF 原始文本与视觉识别来源，不能因存在 PDF 正文字段而丢弃图内手写正文的区域。
3. 云端生成原片保持不变；用原图像素保护正文及高置信度小物件的有限区域，记录区域、覆盖率、变换、版本及输入输出指纹。大面积保护应拒绝，不能变成整页静态替换。
4. 实际后期视频仍经过原有一致性检查，额外检查合成边界、重影和错位。固定参考构图只是映射假设，必须明确复核；不因添加保护层而自动放行。
5. 用原创合成图/视频测试坐标、留白、边缘、重叠、小目标、错误响应、像素保留和未保护区域运动。复用已有失败视频进行有限真实验证，不提交新生视频任务，不更改原失败运行的发布状态。

## 实施顺序

- 先补失败回归，再实现点击裁剪和严格映射，保存私有诊断。
- 补文字来源合并、保护区域规划与实际媒体测试；只有真实质量验证通过后才考虑接入默认生成。
- 对真实既有帧/片段进行有限模型复核，记录所有成功和失败；不将开发小样当成总体准确率或官方成绩。
- 完整回归、依赖检查、敏感文件检查，更新脱敏状态记录后提交并正常推送。

## 边界

不新增书名/页码特例，不读取赛事 Query 或隐藏答案，不降低质量门槛，不自动重试已消费的生成授权。本次不实现正式节点续跑，也不声称完成第二本冷启动或浏览器麦克风验收。

## 实施中调整

局部放大扩展到动作生成和独立视觉复核，两者继续共享同一冻结帧。模型定位必须显式声明坐标系，不兼容猜测缺失字段；既有存储框仍为整帧归一化 xywh，无需迁移。

真实既有视频的保护合成出现明显错位、接缝及重影，4 个候选处理片段均被复核拒绝，另 1 个因保护面积过大未合成。因此保护试验**未接入默认生成**，只提供显式诊断命令及可复现代码；原质量门槛、原失败运行及未发布状态保持真实。后续需先验证可靠配准/跟踪或其他生成控制策略，不能将本轮试验描述为视频保真已修复。
