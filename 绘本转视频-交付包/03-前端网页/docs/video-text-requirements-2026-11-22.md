# 新增视频交互要求：实现与验收记录

依据为 2026-11-22 用户转述赛事组的补充要求：实现方式不限；查找须在交互视频中找到 Query 对应的文本，暂停到该帧并框选；高亮须暂停到对应帧并高亮对应文本；点击物体展示相关介绍和背景。当前未收到正式补充文件、评测字段、多处命中的选择口径或定位精度规则，不据此编造官方时延与评分标准。

## 使用与实现

| 操作 | 当前行为 |
|---|---|
| `查找“目标文字”` | 按原书文字/旁白排序候选视频片段，从实际成片取帧，读取并独立复核目标文字及位置；确认后暂停、跳转并显示轮廓框 |
| `高亮“目标文字”` | 走相同的实际帧核对，暂停后以黄色背景高亮文字，保留可读的原文字形 |
| 语音中的查找/高亮 | ASR 原始转写保存在会话中，再进入同一文字定位路径；无法确定具体目标时请求澄清 |
| 点击物体 | 可靠识别后在该对象独立窗口展示介绍，自动检索原书背景及关系，显示页码证据；不写主对话，不扮演或编造角色经历 |

不需要新增账号或密钥。视频文字核对沿用互动视觉配置；没有引号的文字指令还可能调用文本模型提取目标。对象背景优先使用文本模型，仅配置视觉时也可基于原书页图处理。文字请求、视频帧和裁剪图会发给对应已配置服务；原书背景问答发送原书证据及对象消歧信息，不把视频画面当作原书事实。调用后保留本地运行记录，自动复核不等于人工复核。

内部输出新增 `text_location`：动作、目标文字、采样时间、实际帧 URL/SHA256/尺寸、采样数量和范围；文字框额外标明 `source=verified_video_frame` 和 `presentation=outline|highlight`。帧图保存在该书本轮私有目录。采样时间是提取帧使用的媒体时间，不声称取得解码器原始 PTS；播放器暂停到该时间，再显示同一份实际视频截图，保证框与已核对像素一致，未用原书页图替换视频。

页面必须等帧图和跳转完成才显示标注；载入/跳转失败返回未完成提示。播放、拖动、切书、清空、新点选及中断会清理旧标注；缩放、布局过渡和全屏变化会重新换算位置。中断后的旧请求不能再显示成功回答、播放语音或解锁新请求。

背景响应标注 `background_state=supported|unconfirmed`。同一冻结对象的已确认内容或证据性拒答可复用，标注 `background_execution=reused_same_object`；服务/复核暂时故障不作永久缓存。缓存仅归属该对象，父会话权限检查先于读取缓存；背景失败不取消已识别对象的继续提问能力。

## 实际验证

- 原创六秒视频仅在中段出现一个英文单词。真实配置的视觉服务完成查找、同词高亮和不存在文字三次请求：前两项均返回 3 秒的实际帧及经复核的文字框，约 4.026 秒、3.899 秒；未确认项约 0.776 秒，没有跳转或造框。该组关闭了 TTS，不是完整语音或实际听音延迟测量。
- 真实 FFmpeg 与 HTTP 路由回归同时覆盖文本和音频入口，验证中段文字定位、原始 ASR 转写留存及实际帧可读取；上传截图和原书有该字不构成视频命中。模型边界在离线测试中使用原创可控响应。
- 本机 Chrome 实测暂停框选、黄色高亮、手动拖动/播放清理、窗口缩放、帧加载中按“中断回答”无迟到结果。对象窗口自动背景、主会话无污染和关闭也已操作验证。浏览器这组使用原创视频和模拟外部响应，与上一项真实模型小样分开记录；截图仅保存本机。
- 另复用一个此前可靠识别的授权冻结对象，真实文本服务约 10.603 秒返回背景未确认、无证据，主会话保持为空。泛称对象无法确认原书身份或故事关联时仍需拒绝，不能把这次调用称为真实背景回答成功。原始证据和响应只保存在忽略目录。
- 完整测试命令和最终统计见 `validation-video-text-2026-11-22.json`。回归覆盖错误词串/英文词界、缺字段与坐标、复核拒绝/超时/取消、无证据不跳转、留白与缩放、迟到事件、对象缓存/权限和服务故障恢复。

## 当前限制与下一步

文字搜索最多检查 8 个候选片段、每段 3 帧，最多 3 次独立候选复核，搜索整体上限 120 秒；这些是当前工程策略。没有在采样中确认不代表全片没有该文字。短暂出现、小字、手写、复杂排版和多个相同文本仍需更多授权样本验证；后续应建立实际视频的文字时间索引，扩大覆盖并统计定位召回、框选精度及延迟。英文词间空格保留，避免把 `now here` 与 `nowhere` 当成同一目标；汉字间的换行可规范化比较，原始文字不改写。

对象介绍的基础识别与原书身份对应是两件事。对于泛称对象，应继续补充可核对的实体关联与歧义澄清，不能为展示背景猜测角色身份。本次已有安全拒答个例，尚未完成跨书背景质量评测。

整书视频保真仍是现有阻断项，未发布旧的失败成片，也未新增付费生视频任务。另一份授权绘本从零导入的整书泛化、赛事统一评测、真实麦克风/扬声器听音及指定负责人内容安全复核仍未完成；本轮小样不构成官方成绩或全流程达标。


## 真实绘本补测与对象导航

用户提供“大象在哪里”后，确认这类未指定文字的提问需要实际物体导航。现已增加实际视频对象定位及冻结帧框选；带引号的查找/高亮仍指文字。真实服务及 Chrome 补测已覆盖物体导航、文字高亮、独立对象背景和合成语音输入，见 [真实识别修补记录](recognition-repair-2026-11-22.md)。原有原创样本验证作为历史记录保留，不能代替这次真实素材验证。
