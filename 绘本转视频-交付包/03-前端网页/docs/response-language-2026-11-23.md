# 回答语言跟随本轮问题

用户要求：中文用中文回答，英文用英文回答。适用于主对话、语音转写后的回答、对象窗口追问和视频文字/物体查找结果。绘本语言不覆盖用户本轮的提问语言；用户明确要求“用英文回答”等时，按该要求处理。

## 本次修改

- 前后端使用一致的中英文判断规则，优先识别明确语言要求；引用的查找文字不影响指令语言，英文问题中的短中文角色名也不会直接令整轮变成中文。混合语言采用字符比例启发式，模糊表达仍可能需要澄清。
- 主窗口和对象窗口在文字提问、语音转写后更新本轮语言。语音请求不预先携带上一轮的自动音色；服务端在转写后生成回答，并按中文/英文选择默认语音。用户手动选择的音色仍保留。
- 问答候选文本语言明显不匹配时，在证据复核及朗读前拒绝，不展示或朗读错误语言的候选。返回对应语言的明确失败提示，不偷偷再次提交付费请求。
- 自动对象介绍和自动背景没有用户问题，按绘本语言生成；背景缓存版本更新，旧的固定中文缓存不再复用。后续追问按每轮问题决定。对象介绍优先使用已有的对应语言名称，不能凭空翻译或补写事实。
- 文字/物体定位成功、未确认和服务不可用的回答支持中文和英文；原始引用文本、对象记录和证据保持原文。

## 验证

新增测试覆盖中英文问题、引用外语原文、短中文名字、明确语言要求、文字连续切换、错语言候选拒绝、对象自动背景、定位失败、两种语音接口的转写与配音语言，以及中文/英文的服务端默认音色。

完整回归测试为 **425 项通过**，6 条已知依赖弃用警告；依赖一致性、三个前端脚本语法和差异检查通过。

真实服务只运行两道开发自拟问题，没有读取赛事 Query，也没有补跑导入绘本剩余页面的读图：中文问题返回中文证据不足提示并完成配音；英文问题返回英文答案、原书页码与英文配音。中文候选被证据复核拒绝，表明当前回答质量仍有限，本次没有证明答案正确率或完整整书理解达标。两例服务端耗时约 18.7 秒和 10.0 秒，不是首音听音实测或 P50/P95。

真实浏览器还使用拦截的合成回答检查连续中英文提交，自动音色依次为英文 Ethan 和中文 Cherry，无页面错误。此项仅验证页面控制器和请求内容，不冒充真实模型回答。

模型原始输出、回答音频、引用原书与浏览器测试记录仅存本机忽略目录。尚待更多真实书目和混合语言表达验证。
