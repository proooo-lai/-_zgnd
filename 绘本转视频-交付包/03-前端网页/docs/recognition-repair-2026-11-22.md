# 真实视频识别故障修补与验证

用户报告点击与查找均失效，给出的实际提问是“大象在哪里”。此前原创视频和受控模型响应验证了交互骨架，不能证明赛事绘本的真实识别质量；本轮补做真实素材、真实模型及真实浏览器验证。

## 已确认原因及改动

1. 点击定位同时给出整帧与裁剪图，真实模型多次返回整帧角点却声明 `crop`；换算后不包含点击点，被正确拒绝，但导致用户无法识别。现在定位只看原整帧及同尺寸标记图，只接受 `full_frame` 整数角点；不猜测、自动修正模型坐标单位。去掉原书对象名称提示，减少邻近对象干扰。原书框不用于生成视频定位。
2. 单纯包含点击点仍可能是假命中：真实探测曾为白色背景编造一个小框。候选先经过坐标/置信度/点击点校验，再用原帧、标记图及无标记像素细节复核；不支持或不确定即拒绝。过滤介绍中的调试标记描述，原始模型响应仍保存在私有审计记录。
3. “大象在哪里”原先走全书故事问答，只回答书中地点。新增保守的对象导航语句解析与 `VideoObjectLocator`：从实际成片提帧、定位物体、独立检查候选区域，成功才返回 `object_location`、时间点及实际帧来源。带引号的文字查找/高亮仍走文字定位；明确“故事里”或“第几页”保留原书问答。`Show me`、`Point to` 等同义对象指令也进入同一实际视频核对路径；明确 `in the book` 的指令仍为原书导航。固定对象助手的追问不会切换到主播放器导航。
4. 播放器复用严格实际帧展示：等待帧图、尺寸和跳转匹配后才显示框；失败不播报定位成功。清空历史支持嵌套帧目录，只移除对应会话的轮次，测试覆盖内部软链接不删除外部文件。静态资源版本更新。
5. 本机两个空闲工作台原先加载不同代后端，已在确认无生成任务后重启为当前实现；未修改服务配置，未新增生视频任务。

## 实际验证范围

使用本机已有的一份赛事授权中文绘本单页视频，时长 5.167 秒、1344×768；书库有 12 页原书证据，但视频只覆盖其中一页。未读取赛事 Query/隐藏答案，未修改书名专属规则、手工填框或预设回答。视觉使用本机已配置互动服务，原始素材、对象框、转录、截图和完整回答仅保留于被忽略的本地 `artifacts/recognition-repair-20261122/`。

- 生产交互器在原失败截图上复测：人物、大象、兔子分别识别并通过像素复核，白色背景未识别；修正简化提示后分别约 6.742、7.988、6.691、2.220 秒，关闭了 TTS。这是 4 个开发自拟点的小样，不是总体准确率。
- 真实视频对象导航“大象在哪里”返回实际帧、对象框、时间和来源；真实文字高亮也返回实际帧及文字框。独立调用关闭 TTS，分别约 9.791、9.200 秒。
- Chrome 实际请求已配置服务，没有替换模型响应：文本对象导航暂停且展示 1 个框，约 7.672 秒；文字高亮暂停且展示 1 个黄色框，约 11.236 秒。人工查看本机截图确认框/高亮覆盖相应目标。
- Chrome 真实指针点击大象，独立小助手识别成功，自动返回引用原书页码的故事背景；主窗口历史内容保持一致。背景为自动证据复核结果，仍待指定人员内容安全及事实复核。
- 自拟“大象在哪里”合成语音，经浏览器音频上传、真实 ASR、定位、回答 TTS 后，实际暂停并展示 1 个物体框，约 8.419 秒；转写与自拟语句一致。不是儿童录音、真实麦克风或声学回环验证。

时间均为本机当次网络与服务配置下的单次处理/浏览器结果代理，不是实际听音延迟、P50/P95 或官方成绩。独立复核仍使用相同服务，可能共享模型偏差。

## 验证与限制

完整自动回归及命令见 `validation-recognition-repair-2026-11-22.json`。覆盖错误坐标/裁剪声明、空白假框、像素复核拒绝、请求路由、帧来源、播放器跳转/取消/缩放、语音接口及会话清理。旧流式语音测试改用明确 `in the book` 的原书导航路径，以继续验证旧路径的失败收尾；新增对象导航单独测试，确认定位前不播报故事草稿。

对象及文字查找当前最多检查 8 段、每段 3 帧，最多 3 个候选复核、总搜索时限 120 秒；不是全帧扫描，短暂出现、小字、小物体、遮挡、同类多目标仍可能漏检。未命中须表述“本次未确认”，不能断言全片没有。当前正则仅覆盖明确位置/查找句式；复杂指令仍可能走普通问答，后续需扩充有断言的意图样本及实际视频索引。

本轮没有验证第二本整书冷启动、全部六本赛事书、完整 Query 评测或正式正确率；先前整书视频保真阻断也未因此解除。不新增账号/密钥，沿用当前视觉、文本、ASR/TTS。模型调用会发送对应视频帧、裁剪及用户提问，背景调用发送原书证据；数据仍须处于赛事授权范围。
