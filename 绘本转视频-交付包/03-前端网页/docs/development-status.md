## 验证范围

测试使用自主合成的文本、页面、音频、视频和可注入服务响应，不读取隐藏测试数据、不调用付费 API。完整命令为主工程下 `python -m pytest -q`。本轮最终结果为 **197 项通过、0 失败、0 跳过**，另有 6 条依赖弃用警告（FastAPI/Starlette TestClient 与 PyMuPDF）。独立安装锁定依赖后重跑通过；JavaScript 语法及依赖一致性检查通过；真实启动后 7 个页面/资源/接口检查通过。见 `validation-2026-11-21.json`。

本轮覆盖无关证据、非法类型、跨语言、缓存失效与错误分类、指标存取、实际帧触控和坐标边界、流式取消、语音部分失败、HTTP 输入及媒体转码。测试中的声学记录是构造数据，只验证字段保存/计算，不是实测听音结果。

本机验证使用 macOS Apple Silicon、Python 3.12.14，FFmpeg 来自 imageio-ffmpeg。ffprobe 9.0.2 从提供方公开下载页 `https://www.osxexperts.net/` 获取，二进制 SHA256 为 `8d56278ec2ba80f35138e7dceccb1a72eff951156691d8c733066ebd7628d3f2`；仅存于忽略的 `tools/bin/`，不提交二进制。Python 包及许可证应在最终提交前另行核对并完善来源清单。

## 尚未完成及下一批验收

1. **付费任务恢复与成功产物复用。** 当前仅保存云任务 ID，重启后还不能按节点续跑。应先为输入、配置和输出建立指纹，读取已有任务 ID 并查询结果；状态不明的已提交任务不得直接再次付费提交。用一次中断重启验证成功页零重复提交。预算/调用上限应在真实全书生成前落实。
2. **真实服务小样。** 用户已选择沿用伙伴服务组合，本机配置位置待提供。先验证图文理解、问答复核、ASR/TTS 及代表性页面视频，核对真实接口、数量、构图和文字。外部服务失败必须明确报告，不以固定结果代替。
3. **第二本授权绘本整书冷启动。** 尚未验证。不得改书名规则、人工预置原文/对象框/答案；全新 PDF 导入到问答、点读和运行记录必须完整走通，人工介入与失败逐项记载。三页演示或单元测试不构成泛化验收。
4. **画面保真与人工复核。** 已有三帧采样质量检查继续保留，但不能证明全片无问题。新增角色、文字漂移、黑块等需在真实输出中验证；年龄选择及复核责任人入口仍需补充。自动审核不等于人工审核。
5. **正式评测及性能。** 统一接口及最终交互延迟门槛未更新。真实 Recall@3、最终正确率、证据支持率、拒答、触控和 P50/P95/超时率均尚未测定；回答正确率 ≥0.60 是已知赛事基础门槛，本轮未证明已达到。

问答新增一次证据复核会增加调用费用及首音延迟；同一模型生成和复核可能共享偏差，真实样本需人工独立核验。当前仍是语言模型检索/判断，未宣称零幻觉。扫描页 OCR 与描述的准确性也是上游限制。
