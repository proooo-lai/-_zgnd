## 启动

以下命令在 `绘本转视频-交付包/03-前端网页` 下执行，建议 Python 3.12：

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.lock.txt
.venv/bin/python run.py
```

打开 <http://127.0.0.1:8765>。Windows 可沿用主工程安装和启动脚本。FFmpeg/ffprobe 安装、模型配置及验证命令见主工程 README。

页面和数据存储在本机；启用模型后，页面、问题或待生成内容会按任务发送到所配置的外部服务。配置模板使用环境变量引用，不包含密钥。
