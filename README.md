# 纸书智伴：代码演示

本仓库提供可公开运行的原创示例《花园里的风筝》，包含两页原创 SVG 插画和人工编写的文字与对象框。界面串起翻页、浏览器朗读、语音或文字提问、页面原文证据检索、无依据拒答、触控识物及页面轻动效。导入的新绘本可调用百炼 Qwen-VL 视觉模型逐页分析；每次分析和提问都生成 `run_id`，可在页面的“运行记录”中查看步骤。

最终目标是输入一本获授权且符合系统输入格式的新绘本后，由同一套流程完成导入、理解、生成、问答和触控。当前已可导入不同 PDF 绘本、逐页预览，并通过可配置的百炼兼容接口完成页面文字、人物、场景、对象、关系和不确定项的结构化分析。互动视频、正式 ASR/TTS、自动质量复核和评测接口仍在后续路线中。

## 启动

需要 Node.js 22；导入 PDF 还需安装 Poppler，并确保 pdfinfo 和 pdftoppm 可执行。无需安装 Node.js 第三方依赖。调用百炼分析前，在本机环境变量中配置（可参考 `.env.example`，项目不会自动读取 `.env`）：

```sh
export DASHSCOPE_API_KEY="本机密钥"
export DASHSCOPE_BASE_URL="https://ws-la8oqqwon835guxb.cn-beijing.maas.aliyuncs.com/api/v1"
export BAILIAN_VISION_MODEL="qwen3-vl-plus"
```

然后运行：

```sh
node server.mjs
```

终端会输出实际访问地址。默认从 `http://127.0.0.1:4173` 开始，若端口已占用则自动尝试后续端口。验证命令：

```sh
node --test
```

演示顺序：打开首页，浏览两页原创示例，播放页面动效，切换“画面识物”点击已标注区域，再通过语音或文字提问。用“小鹿捡到红色风筝”检查来源跳转，用页面中未出现的事物检查拒答。

## 导入一本新绘本

在首页展开“导入一本绘本”，输入书名、选择 PDF、确认本赛事开发与演示使用授权，然后上传。当前接受最多 20 MB、1–40 页的 PDF。上传后可在“选择绘本”中切换已导入图书，并逐页查看由 PDF 生成的图片。书籍和页面使用独立 ID；原始 PDF、页面 PNG 及清单保存在本机的 .local-books/，不提交到公开仓库。导入运行记录可查看预处理步骤和待处理状态。

新书会标记“待分析”，其页面原文和对象列表保持空白；点击“开始内容分析”后逐页调用视觉模型，状态依次为 `pending -> analyzing -> completed/failed`。只有 `completed` 才开放问答、朗读和识物；配置缺失、服务失败或模型返回非法 JSON 都会保留失败原因，不会伪装成完成。原始页面清单保存在 `book.json`，模型结果另存为 `analysis.json`，读取绘本时才合并展示。原创演示书仍使用人工编写的原文与对象标注，界面会明确标注其来源。

本地接口：POST /api/books?title=书名 使用 application/pdf 请求体及 x-rights-confirmed: true 请求头；POST /api/books/:id/analyze 启动逐页视觉分析；GET /api/books 查询书架；GET /api/books/:id 查询绘本清单；GET /api/books/:id/pages/:n.png 查看导入页。对于已具备页面证据的书，POST /api/ask 的请求体须包含当前 book_id，避免跨书引用。书架和页面预览不对外开放鉴权，仅适合受控本地演示环境。

如果本机获准使用赛事样本，可设置 `BOOK_DATA_FILE` 为本机 JSON 文件路径来查看原有演示数据。该 JSON 的 `pages[].asset` 必须指向本机 `public/assets/` 下的相应图片。此配置只切换本地演示数据，不是新书导入能力；这些样本文件及其衍生文本不得提交到公开仓库。

## 能力与来源边界

| 环节 | 当前实现 | 尚待接入 |
| --- | --- | --- |
| 内容理解 | 通用 PDF 导入与逐页预览；百炼 Qwen-VL 逐页结构化分析及失败状态记录 | OCR 专项优化、质量复核和正式评测 |
| 互动内容 | 本地页面切换与轻动效；浏览器朗读 | 可审查的故事、语音和视频生成，视频时间轴与审核 |
| 问答 | 本地页面原文检索、页码引用、证据不足拒答 | 视频字幕/关键帧检索、正式 ASR/TTS、正确率评测 |
| 触控 | 人工演示标注和 `contain` 坐标映射 | 自动定位、视频帧对象索引与识别准确率评测 |
| 编排 | 分析和提问步骤、耗时、模型版本可由 `run_id` 查询 | 生成任务状态机、失败恢复、缓存和完整模型注册 |

浏览器语音识别及朗读能力取决于所用浏览器和权限。演示服务不接收原始录音；若用户提交语音识别结果，服务仅在当前进程内保留原始转写和编辑后的问题，最多保留最近 100 次运行记录，重启后清空。请勿在此原型中输入真实儿童个人信息。

## 仓库边界

公开仓库只保存代码、测试、协作约定、路线图和原创示例。赛事绘本、Query 音频、人工转录、对象标注、参考资料和模型凭证保留在本机并由 `.gitignore` 排除。后续代码修改通过本仓库版本记录同步；同步前检查待提交文件、运行测试，并确认没有受限素材或密钥。

正式评测接口、交互延迟门槛及跨书自动处理仍待接入与验证。当前本地测试不能证明回答正确率达到 0.60，也不能证明四项赛题任务已全部完成。
