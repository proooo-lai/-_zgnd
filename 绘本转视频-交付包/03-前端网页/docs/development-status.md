## 验证范围

测试使用自主合成的文本、页面、音频、视频和可注入服务响应，不读取隐藏测试数据、不调用付费 API。完整命令为主工程下 `python -m pytest -q`。本轮最终结果为 **197 项通过、0 失败、0 跳过**，另有 6 条依赖弃用警告（FastAPI/Starlette TestClient 与 PyMuPDF）。独立安装锁定依赖后重跑通过；JavaScript 语法及依赖一致性检查通过；真实启动后 7 个页面/资源/接口检查通过。见 `validation-2026-11-21.json`。

本轮覆盖无关证据、非法类型、跨语言、缓存失效与错误分类、指标存取、实际帧触控和坐标边界、流式取消、语音部分失败、HTTP 输入及媒体转码。测试中的声学记录是构造数据，只验证字段保存/计算，不是实测听音结果。

本机验证使用 macOS Apple Silicon、Python 3.12.14，FFmpeg 来自 imageio-ffmpeg。ffprobe 9.0.2 从提供方公开下载页 `https://www.osxexperts.net/` 获取，二进制 SHA256 为 `8d56278ec2ba80f35138e7dceccb1a72eff951156691d8c733066ebd7628d3f2`；仅存于忽略的 `tools/bin/`，不提交二进制。Python 包及许可证应在最终提交前另行核对并完善来源清单。

## 同日追加：真实服务联调与兼容性修补

- 使用用户指定的赛事授权素材，重新解析一份中文 PDF 的 12 页，对其中连续 3 页实际调用视觉服务；另外对英文 PDF 的一个读后互动页验证文本提取/摘要。未读取赛事 Query、隐藏题目或标准答案。书页、OCR、对象框、音频和模型原始输出只保存在被忽略的本地 `artifacts/`。
- 三页视觉输出通过 schema；三页旁白覆盖与顺序通过结构校验。两道开发自拟的有证据问题返回对应页码，一道缺证据问题拒答，三道均生成回答音频。这只是 3 个小样行为，不是正式正确率或整书验收；角色身份推断及内容安全仍待指定人员复核。
- 修复后又执行一次合成提问音频 → ASR → 有证据问答 → 回答音频。转写与自拟输入一致，输出音频长度与实际 PCM 一致；不包含真实麦克风或实际听音测量。
- 视觉逐页调用约 62.2、83.4、95.1 秒；两道有证据问答的服务端处理约 6.1、39.3 秒，拒答约 2.6 秒。它们是本机、当次网络、当前服务配置下的单次小样，不是 P50/P95，更不是官方延迟成绩。视觉问答速度是下一轮需解决的问题。
- 百炼文件式 TTS 返回的 WAV 使用流式占位长度，导致标准音频读取器把几秒的声音标成约 12.4 小时。现在仅修正已知占位长度，保持 PCM 不变；普通截断、无效结构和半个采样会拒绝并清理文件。对本次三个实际下载文件复验，声音数据完全一致，时长修正为 1.84、5.92、11.76 秒。
- 核对 MiniMax 官方视频 V2 文档后，修正 `MiniMax-H3-Lite` 不支持 `adaptive` 的参数问题：选择最接近参考图的支持比例，并保存实际请求参数。视频权限、计费、生成与轮询尚未真实验证。

## 同日追加：真实视频生成与实际帧交互

用户保存视频凭证后，以前一轮授权 PDF 的一页生成一个短片；仅提交一次视频任务，没有追加视频生成。MiniMax H3-Lite 实际完成提交、轮询及下载；请求 5 秒/768P/16:9，下载片为 5.167 秒、1344×768、24fps、H.264，生成与下载合计约 50.6 秒。三帧自动质量核对为 sampled_consistent；这不等于逐帧或指定负责人完成人工审核。

基于该片 2.58 秒的实际帧，完成一道画面数量问答和有对象/留白的点读小样；问答经独立模型证据复核，证据作用域为 current_frame。服务端画面问答约 59.0 秒，修补后对象点读约 9.4 秒、留白约 7.3 秒；这些包含服务处理和回答语音合成，不是实际听音延迟，也不能用单例计算准确率或 P50/P95。

真实联调发现触控提示中仍传入了原书对象框，模型逐值沿用了原图坐标，而实际帧存在留白/缩放和物体运动，定位框因此偏移。已将触控上下文改成名称字段白名单，不再把原图 bbox 或嵌套几何数据提供给该次定位；同片复测返回了新的实际帧位置。静态 contain 命中路径保持原行为。这个修补消除了坐标输入污染，不保证视觉模型永远定位准确。

本机书库加入明确标注的单页、无旁白联调样片，保持待人工复核状态；样片和素材不提交。验证了书库可见和 MP4 HTTP 范围读取。源码、回归和脱敏运行摘要提交；完整测试为 **213 项通过、0 失败、0 跳过**，另有 6 条依赖弃用警告，见 `validation-video-2026-11-21.json`。此前各记录保留为当时的历史状态。
