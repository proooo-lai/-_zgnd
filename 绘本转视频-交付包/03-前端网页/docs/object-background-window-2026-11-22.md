# 对象背景与可移动窗口修补记录

日期：2026-11-22。用户反馈对象背景生成失败，并要求对象小助手窗口可移动。本轮仅修改既有对象交互及窗口，不重新生成全书，不读取赛事 Query 或隐藏答案。

## 问题及处理

既有真实请求曾在文本提交连接或 TTS 音频下载处失败；本轮使用同一配置的新连接、最小文本调用和短句 TTS 均成功，未发现需要更换密钥的证据。不能据此保证外部网络永不波动，也未修改 POST 自动重试策略或关闭证书校验。

另确认背景链路只传递对象名称等简短字段；名称为“人物”等泛称时，丢失了区分对象的画面线索。现在仅在背景任务中，把可靠点选结果的描述作为 `selected_object.visual_reference_only` 传入，限制为 800 字符。它只用于消歧，仍在复核上下文 `context_not_evidence` 中；回答事实与姓名必须由原书正文、页面描述等支持，并经过原有独立复核。身份不明时允许明确说明身份未确认，并介绍当前原书页的相关场景，不把其他人物动作归给所选对象。

背景结果使用 `object-background-context-v2` 记录版本。旧版或无版本缓存不继续沿用；当前版本已确认结果及证据性拒答仍可在同一冻结对象内明确复用，临时复核/连接故障不永久缓存。兼容与边界有原创合成测试覆盖。

背景请求或复核暂时失败后，显示“重新获取背景”按钮，沿用同一对象和冻结帧。只有用户点击才重新请求；没有自动重复未知提交。按钮在处理中禁用，关闭、换目标和中断仍使用原有取消及版本守卫，旧结果不能进入新窗口或主对话。前一次受理未知时，错误说明仍保留，用户应留意可能重复计费。

## 窗口操作

从标题栏拖动即可移动窗口，支持鼠标及触屏；标题栏可用 Tab 聚焦后按方向键移动，Shift 加方向键大步移动。拖动使用指针捕获，移出标题栏后仍能跟随，松手、取消或关闭会释放。关闭按钮和输入区不触发拖动，聊天继续保持独立。

窗口按可见视口限制位置，缩放、尺寸、全屏及可见视口变化后重新约束。内容高度变化时也约束位置，避免背景生成后窗口变高而遮住底部。关闭后同一页面内保留移动位置，刷新不作跨页面位置持久化。

短屏实测另发现：在 430×340 可见区域中，旧聊天区最小高度导致发送按钮超出面板。现允许聊天区收缩、输入区滚动，同时保留标题栏；修补后输入框和发送按钮均落在面板内并可操作。
