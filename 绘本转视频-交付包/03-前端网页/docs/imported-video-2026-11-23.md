# 既有成片导入与全书播放测试

用户指定既有 MP4 作为全书测试视频。本次新增独立导入工具，不重新生成故事、视频或配音，不覆盖原书库。视频、PDF、字幕、逐页时间清单、页面图、模型结果和截图均只保存在本机忽略目录，不上传公开仓库。

## 当前本机结果

- 已新增一项全书测试书目，关联正确的授权原书 PDF、12 页原图、原始 PDF 文字及 12 条配套旁白字幕。
- 原片 170.7 秒，1920×1080、30fps、H.264；一个 AAC 配音音轨。复制后视频 SHA256 与用户指定文件一致，完整解码通过。
- 逐页稳定展示时间根据源片段时长、转场参数、字幕及实际视频采样核对。转场与片尾保留为未映射时段，不强行归属任何原书页。触控仍须读取实际视频帧，不使用原书对象框代替。
- 最初的读图请求发生连接中断，3 页已完成。用户选择“先导入视频，暂不补跑读图”，因此最终导入只复用这 3 页经过校验的同输入/同配置缓存，其余 9 页保留原始页图与 PDF 文字，明确标注读图待完成。未再次请求模型。
- 原书文字与改编旁白分开保存；字幕不覆盖原文，也不作为原书事实的独立证据。初筛和人工复核是不同状态，本次仍等待指定责任人复核。

这支持全书播放测试，不代表整书理解、交互正确率、视频质量或任意绘本冷启动生成验收通过。

## 使用入口

本机工作台书架选择带有 `film_v7` 的全书测试书目。页面标签显示“导入视频 · 全书测试”，顶部提示未完成读图的页码。已有的其他全书测试书目保留。

## 通用导入方式

```sh
.venv/bin/python tools/import_video_book.py \
  --pdf /path/to/authorized-source.pdf \
  --video /path/to/narrated-film.mp4 \
  --subtitles /path/to/film.srt \
  --manifest /private/path/import-manifest.json \
  --book-id unique-import-id --cached-only
```

不带 `--cached-only` 会使用已配置的原书读图服务，可能产生模型费用。带此参数时仅查有效缓存，缺失理解如实标注，不提交模型请求。工具不调用故事生成、视频生成或 TTS；已有成片必须包含完整音轨。

清单为本地 JSON，字段为 `title`、`pdf_sha256`、`video_sha256`、`subtitle_sha256`、`scenes`。每个 scene 包含 `page_number`、`start`、`end`、`subtitle_indices`。时间单位为秒，采用左闭右开区间，须完整按序覆盖所有 PDF 页，每页一次；区间不能重叠，每条字幕须按序关联一次。字幕允许在前置转场中开始，不得延续到下一页稳定展示区间。未映射时段不提供当前页触控上下文。

导入会校验指纹、解析 SRT、检查音视频、完整解码、提取 PDF、复用或生成原书理解，再发布书架入口。失败仅保留诊断目录，不发布 `book.json`；被内容初筛阻断的作品也不发布。新尝试必须使用新的书目 ID，避免覆盖已有成果。更换输入、模型、提示或缓存版本会使旧理解失效。

## 实际验证与限制

- 完整测试：403 项通过，6 条已知依赖弃用警告；依赖一致性、JavaScript 语法、差异空白检查通过。
- 浏览器逐页核对 12 个稳定区间的页码，另检查 1 个转场和 2 个片尾时刻，均未出现错误页码。
- 浏览器在首、中、尾 3 个有旁白的时刻正常推进画面，音频分析器均检测到非零信号，无播放器错误或页面异常。该检查是浏览器音频代理，未测真实扬声器听音或交互首音延迟。
- 独立代码复核发现并修复内容阻断后仍发布的问题；新增实际阻断回归测试，随后复核通过。
- 按用户要求，本次最终导入后没有额外调用模型，未重测语音问答、文字定位、对象识别及背景回答；第 4–12 页图像理解仍待完成，PDF 文字可能不完整。未读取赛事 Query 或隐藏答案。
- 未对全片做逐帧人工内容检查。所有成片内容、角色保真、年龄适配及复核责任人仍待人工确认。

本机详细导入记录、文件指纹、字幕、逐页理解和浏览器截图保存在对应 `data/` 与 `artifacts/` 目录。公开报告仅记录汇总，不包含赛事页面、转录或对象标注。
