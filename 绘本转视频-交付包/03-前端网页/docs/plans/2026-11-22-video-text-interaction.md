# 视频文字定位及对象背景补充实施计划

依据：2026-11-22 用户转述赛事组新增要求。实现方式不限；查找须在交互视频找到 Query 对应文字，暂停到实际帧并框选；高亮须暂停到实际帧并高亮文字；点击物体展示相关介绍和背景。尚未收到补充文件或正式评测字段，本轮不推定额外格式、时延数值或字级评分标准。

本轮沿用当前 Python/浏览器及已配置模型服务，不重新生成视频、不读取赛事 Query 或隐藏答案。完成后的代码、原创测试和脱敏文档按约定正常推送。

## 1. 视频文字定位

- 新建 `storybook/video_text.py`：解析明确文字查找/高亮意图；原书文字、旁白只用来排序候选片段，不能证明视频文字存在。
- 按有限采样策略提取实际成片帧，模型返回帧编号、实际文字、严格 0–1000 端点框及置信度；独立调用复核实际帧/局部。缺字、错字、不确定、无效框都不放行。
- 返回实际时间点、帧图及指纹、帧坐标、框选/高亮模式与采样范围。未命中必须如实表示本次采样未确认，不能宣称全片不存在；没有可靠时间和框时不跳转或造框。
- 接入 `Interactor.ask`，使文字、上传音频和麦克风转写共享处理；旧文字定位路径不再仅取片段起始 0.2 秒套框。

## 2. 播放器标注

- 框选与高亮有明确不同样式，标注覆盖实际视频帧，不跳原始 PDF 替代。
- 定位成功暂停并跳到核对时间，用保存的同帧图保证框与像素一致。帧加载失败或跳转失败不冒充成功。
- 播放、拖动、切书、清空及新点击时清理旧帧/旧框；处理迟到请求，保持 contain 留白和缩放换算。

## 3. 对象介绍与背景

- 可靠识别后先展示对象介绍，再在对象自己的窗口自动请求原书背景；背景走现有检索与证据复核，无法关联时明确说明，不猜身份。
- 背景请求归属对象会话、冻结帧和原父会话，保留取消及隔离；失败不使已识别对象失效。重复背景读取可复用同对象结果并标明来源，不重复计费调用。
- 背景优先走文本服务，也支持仅视觉服务基于原书页图处理；服务/复核暂时故障不缓存为永久结果。已识别外貌不等于原书身份已确认，关系不明确时保留拒答。

## 4. 验证

- 先失败后修补：原创文本/视频验证中后段才出现的文字、源书有而视频无、错误拼写/坐标/复核、未命中和采样范围。
- 实际执行浏览器控制代码，覆盖跳帧后标注、高亮、留白、旧标注清除、迟到事件及对象自动背景不写主窗口。
- 完整离线回归、依赖/语法检查；复用授权已有成片作有限真实模型诊断，不重抽视频，不提升旧失败运行的发布状态。真人麦克风/实际听音等未测项单列。

实施结果及未完成范围见 `../video-text-requirements-2026-11-22.md`；最终离线结果为 363 项通过，真实模型小样与浏览器的模拟服务边界分别记录。整书保真与泛化未因本轮交互修补而完成。
